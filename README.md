# PetGo Frontend

React + Vite frontend cho nền tảng PetGo.

## Cách chạy

```bash
npm install
npm run dev
```

Backend mặc định được proxy sang `http://localhost:8080`.

Frontend gọi API qua `/api/v1/...`.

## Các nhóm chức năng chính

- Auth / profile / thú cưng
- Dịch vụ theo khu vực / đặt lịch
- Ví / membership / shop
- Admin: khu vực, dịch vụ, booking, voucher, nội dung
